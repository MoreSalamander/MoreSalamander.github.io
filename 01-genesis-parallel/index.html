The question it answers

"What is happening outside the studio that should change what we do?"

The loop

STUDIO HEAD objective
  → SIGNAL INTELLIGENCE EXECUTIVE     owns the objective, not the searches
  → RESEARCH PLANNER                  Gemini decomposes it dynamically
  → MARKET ∥ TALENT ∥ INDUSTRY ∥ STRATEGIC     four locked cognitive domains
  → PARALLEL SEARCH API               external observation, at runtime
  → EVIDENCE → VERIFICATION           VERIFIED / UNVERIFIED / CONFLICTED, conflicts kept
       ↑ PROVENANCE AUDIT             re-opens a claim's pages and quotes what they say NOW
  → KNOWLEDGE GRAPH                   Source → Evidence → Claim → Entity
  → STRATEGIC COGNITION → RECOMMENDATION     confidence + evidence trail
  → COVERAGE AUDIT                    which findings rest on nothing verified?
  → NESTED QUESTIONS                  each shortfall becomes a question of its own (≤4, never recursive)
  → STUDIO HEAD                       approve / reject / request more research

What makes it not a search chatbot

  • Verification states are computed, not asserted. A claim with no corroboration is UNVERIFIED on the record; a contradiction is CONFLICTED and shown, never resolved by the model.
  • The provenance audit puts no model between page and panel. A claim's recorded pages are re-opened on demand and quoted verbatim, or honestly reported UNREACHABLE.
  • The answer is read back against its own graph. The coverage audit finds which findings rest on nothing verified, and turns each shortfall into a nested question that is researched like one you typed — bounded to four, and a raised question never raises more.
  • The human authority boundary is a workflow signal. Missions run in a Temporal worker; approval is a durable signal the Studio Head sends.
