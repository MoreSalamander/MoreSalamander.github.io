The decision lifecycle

Proposal → Evidence Package → Criterion Scores (code) → Policy Findings (code, Bob-built engine)
  → Governance Verdict → RECOMMENDED → Studio Head signal (approve / reject / request revision)
  → AUTHORIZED → Authorized Software Objective → IBM Bob → ACTIONED → CLOSED → DataHub

What is computed, and what is not

  • Criterion scores are computed in code from declared weights. Gemini evaluates qualitative criteria with citations; it never emits the aggregate.
  • A versioned policy engine judges compliance in code — COMPLIANT / VIOLATION / NEEDS_REVIEW / EXEMPT, each finding citing its clause. The governance verdict is a function of findings.
  • Authorization is a durable Temporal signal held for a human. The worker can die during the pause, the approval can land with no worker alive, and the decision resumes when the worker returns — demonstrated, not described.
  • Approved decisions become software. An Authorized Software Objective is executed by IBM Bob, and the delivery evidence is attached to the dossier.
