Everything in the studio

Every project, grouped by what it is — each an instance of the same idea: an AI model is a powerful but unreliable proposer, wrapped in a deterministic scaffold that decides what's allowed to be true.

The model proposes; the scaffold disposes. Knowledge, story, video, music, code, games, play — the model fills it in, deterministic gates decide what survives.

Veritas Dynamics
An LLM proposes; a deterministic scaffold decides. Reliable autonomous organizations, built as a trust system.
autonomous orgs · verification
one-engine
Research, software, university, and web converge into one engine — through a Universal Engine Contract that the composed system exposes as well as consumes. Each engine keeps its own repo, agents, graphs, and DataHub platform (not a line of the four was modified); a federation adds only the cross-domain edges, and Temporal owns durable execution while DataHub owns knowledge. Because a composite is indistinguishable from a leaf, a second system composes the whole thing as a single capability — and the move is available again.
composable intelligence · recursive composition · engine of engines
research-engine
Enter any topic; a planner staffs ten specialized research agents, an async orchestrator fans them out across live sources in parallel, and every claim passes a deterministic evidence gate before it enters a graph. A session Context Graph (emitted to DataHub as lineage) feeds a persistent Knowledge Graph that remembers across sessions — the engine never relearns what it already verified.
research intelligence · context + knowledge graphs · evidence-gated
design-engine
An AI web design organization on the research-engine substrate: six research workers analyze real websites into abstract traits, a design Knowledge Graph learns what industries expect, and a gated synthesizer + typed component library generate original, buildable Next.js sites — WCAG contrast and anti-copying enforced by math, reviewed and auto-improved by five agents.
website generation · design intelligence · engine on engine
code-engine
An AI software engineering organization: idea → gated spec → parallel research (live PyPI + OSV) → generated FastAPI projects that carry their own semantic model as a sidecar — every file knows its component, feature, and requirement. Verification is execution (ruff + the project's own pytest), impact analysis is graph traversal, and a red suite is reported red.
software generation · living system model · verification is execution
learn-engine
A personal university: goal → validated prerequisite roadmap → six research agents → adaptive teaching against an evidence-based learner model. Mastery is computed (streak + breadth), review is spaced, misconceptions get Socratic repair — and generated code exercises pass a code-executes gate: the reference solution runs sandboxed, and when the model's claim disagrees with execution, execution wins.
education intelligence · evidence-based mastery · code-executes gate
Entropy OS × DataHub
The hackathon entry: press Entropy OS and descend the layers — down to real org runs whose gate verdicts live as DataHub assertions (54 ✓ / 26 ✗, failures included, because fail-closed systems have failures). Every number is a frozen export of a real DataHub instance; every stage links to its commit.
DataHub hackathon · verification provenance · queryable governance
hunter-engine
The domain-agnostic scout/gate/debate/mission substrate every Hunter AI is built from — extracted from Crypto Hunter AI once an audit found ~80% of it had no crypto in it at all. Two extension points let a new domain plug in without forking.
shared substrate · extraction
Opportunity [Agency AI]
An agent organization of agent organizations. Independent "___ Hunter AI" engines each hunt opportunity in one domain; Opportunity reads across all of them and decides how your finite time and money should actually be spent today — arbitration, not another opinion.
meta-org · cross-domain arbitration
Crypto Hunter AI
The flagship Veritas org: an army of frontier agents hunts crypto earning opportunities on the live web — and one deterministic, fail-closed gate decides what you're allowed to trust. Scouts find, skeptics investigate, the scaffold verdicts, you get a ranked daily mission.
agent org · adversarial verification · live intelligence
Collectible Hunter AI
Hunts collectibles selling under value against independently-confirmed comps. The gate confirms the arbitrage math; authenticity and condition risk are argued in debate, not gated — no clean deterministic check exists for those.
agent org · comp-arbitrage gate
taichi-academy
Thirty GPU-simulation lessons on one ladder — reaction-diffusion to a universe sandbox — taught by building, read in the academy's own reader. The same projects the Entropy OS Vending Machine packages into disposable lesson containers. Now fully open source.
learning · GPU sims · the vending machine's shelf
Hackathon Hunter AI
The fourth Hunter engine — born inside the DataHub hackathon judging window, DataHub-native from its first commit. Hunts hackathons and prize challenges; the gate demands the official listing, a future deadline, a documented prize, and parseable eligibility — all hard, fail-closed. Its first real cycle verified two live Devpost events and rejected one, same day it was born.
agent org · listing gate · born in the judged window
Free Money Hunter AI
Hunts unclaimed property, tax refunds, and settlement claims. A near-binary official-registry gate does almost all the verification work, leaving little for the debate beyond claim-effort-vs-payout sizing.
agent org · registry gate
The House Always Wins
A cinematic AI heist you watch, not play — six AI crew rob a casino while a seed-locked brain keeps the house's edge.
simulation · game AI
