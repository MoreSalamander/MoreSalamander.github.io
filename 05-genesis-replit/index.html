The loop

Authorized Software Objective → Gemini specification + test checklist
  → Replit Agent constructs → evidence (sessions · tests · deploy)
  → computed assessment → DELIVERED (or an honest INCOMPLETE, with the reason)

Delivery is computed from verified checklist coverage plus a live deployment; nothing declares itself done.

Two ways to run, one code path

ModeHow an objective arrivesNeeds
Standalone (the submission)a seeded governance record, aso-dtb-001 — the Dailies Turnaround Boardnothing else running
Federated (Genesis OS)POST /api/objectives from the federation, carrying the objective the decision system authorizedthe Genesis OS layer

The Bay cannot tell the two apart, and that is enforced, not incidental: the seeded objective is ordinary pre-loaded data, and branching on an objective's provenance is forbidden by the contract. A judge can run it with every sibling switched off.

Built with Replit Agent — and finished credit-free

The Bay was built from an empty Replit app in one Agent session against a contract and objective embedded in the prompt: every contract endpoint, SQLite plus a JSONL audit, Gemini on Vertex through a service account (the Agent's request for a bare API key was refused; Vertex is the permanent credential), the blueprint console, eight acceptance checks passed. Then the credits ran out until after the deadline, and the Studio Head chose to finish credit-free rather than scrap the track: the track rule — built using Replit Agent as part of the development process — was already satisfied by that first session, on the record in docs/agent-evidence/.

Status

The application code in the repository is authored by Replit Agent; the contract, objective, and acceptance bars are authored by the studio. Parked with the rest of Genesis on September 12, 2026.
